# Exception process

Every exception must record:

- Control being bypassed
- Business and technical justification
- Scope and affected repositories/environments
- Risk rating
- Compensating controls
- Security and Product Owner/Manager approvals where applicable
- RSAM variance reference when audit approval is required
- Owner
- Start and expiration dates
- Remediation plan

Coverage transition exceptions must not be blank and should expire after the application reaches the 80% baseline.
